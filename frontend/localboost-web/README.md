# localboost-web

LocalBoost frontend — migrated from `fixna-localboost/frontend`.

- **Stack:** Next.js 16, React 19, TanStack Query
- **Routes:** dashboard, businesses, campaigns, leads, login/register

## Local dev

Copy `.env.example` to `.env.local`, then:

```bash
npm --prefix frontend/localboost-web run dev
```

## Build

```bash
npm run build:localboost
```
